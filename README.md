## 🔑 Accesso ai writeup completi / PoC

1. Apri la box → bottone **Request access su GitHub** → si apre una *issue* precompilata.
2. Inserisci il tuo **username HTB** e il motivo, invia.
3. Vieni aggiunto come **collaboratore** al repo privato (writeup full + script).
4. Al **retire** della macchina il contenuto diventa pubblico — nessuna richiesta necessaria.

## 🗂️ Struttura

```
index.html              # hub (questa pagina come sito)
assets/theme.css        # tema condiviso (un'unica fonte per tutti i writeup)
template/               # scheletro per nuove box
machines/<box>/         # landing pubblica per ogni box
```

Nuova box: copia `template/writeup-template.html`, aggiungi una card in `index.html`,
metti writeup full + PoC nel repo privato. Il tema è automatico (`assets/theme.css`).
